# Thankuuu. — A Little Book of Appreciation

A free, static birthday thank-you storybook made with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a modern browser. For best results, use a simple local server or VS Code Live Server.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the `assets` folder (keep the folder structure).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/root`, then Save.
5. Wait for GitHub Pages to publish the site.

## Personalize
- Replace `assets/teddy.png` with your own transparent teddy cutout if desired.
- Edit the message text in `script.js`.
- The Instagram link is currently set to `https://www.instagram.com/Pvt_Shivaayu/`.
- The background music is a gentle original music-box-style tune generated locally with Web Audio. It starts only after the visitor taps Sound on, because browsers require a user gesture.
- Page flips and party sounds are generated locally. No backend, database, API key or paid service is required.

## Files
- `index.html` — page structure
- `style.css` — design, scrapbook styling and 3D page animation
- `script.js` — page content, navigation, audio and celebration effects
- `assets/teddy.png` — cutout made from the teddy reference supplied by Shivaayu
- `assets/scrapbook-reference.jpg` — supplied scrapbook mood reference
